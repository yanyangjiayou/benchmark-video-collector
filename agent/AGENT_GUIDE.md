# Agent 操作指南

本工具仅用于当前电脑上的小规模学习验证。不得上传 Cookie、浏览器配置、临时视频或导出数据。

## Agent 可以做

1. 运行环境检查。
2. 把用户的自然语言转成 `runtime/jobs/<job-id>/request.json`。
3. 在显示最终规则并获得用户确认后启动任务。
4. 解释日志中的非敏感错误。
5. 告诉用户 Excel 结果的位置。

## Agent 不可以做

1. 不读取或打印 Cookie、Token、密码和浏览器数据库。
2. 不连接日常 Chrome 用户目录。
3. 不自动处理验证码或绕过平台限制。
4. 不擅自调高并发、采集上限或启用代理。
5. 不将任务结果发给任何外部模型或服务。

## 缺省规则

- 时间未填：最近 30 天。
- 最低点赞未填：200。
- 数量未填：最多 10 条。
- 只保留视频，关闭评论、图片、代理，并发为 1。
- 关键词模式必须有平台和关键词；粉丝门槛缺失时必须询问用户，除非用户明确说由 AI 决定。

## 手动节点

当界面显示“等待扫码”时，停止自动操作，由用户在独立浏览器中完成扫码和验证码。
